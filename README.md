# Day 08: Lambdas & Higher-Order Functions in Kotlin

Welcome to Day 8 of my Kotlin learning journey! 🚀

In this section, I explored the power of **Higher-Order Functions** and **Lambda Expressions** in Kotlin, moving away from standard function declarations to write cleaner, more concise code.

## 🧠 What I Learned

- **First-Class Functions:** Understanding how Kotlin treats functions as data types, allowing them to be stored in variables, passed as arguments, and returned from other functions.
- **Function Types Syntax:** Learning how to explicitly define function signatures using the `(Input) -> ReturnType` syntax (e.g., `() -> Unit` or `(Int) -> String`).
- **Lambda Shorthand Syntax:** Making expressions concise by utilizing the implicit `it` keyword for single-parameter lambdas and omitting unnecessary parameter names.
- **Trailing Lambda Syntax:** Passing lambdas outside of function parentheses to improve code readability, a pattern heavily used in Jetpack Compose.
- **Higher-Order Functions in Action:** Implementing a custom `trickOrTreat()` function that handles functions as both inputs and outputs.
- **Built-in Functions:** Working with standard Kotlin higher-order functions like `repeat()` to execute blocks of code efficiently.
- **Nullable Function Types:** Declaring and safely invoking functions that can be `null` using the `?.invoke()` pattern.

## 🛠️ Tech Stack & Prerequisites
- **Language:** Kotlin
- **Environment:** Kotlin Playground / IntelliJ IDEA
